# 靜宜大學沙鹿校區 · 新生校園資源走讀

> 不用照路線走，想去哪就去哪。走到資源附近手機會叮一聲，打卡就能收集印章。

給新生用的校園實境導覽網頁。打開手機定位，在校園裡自由探索；靠近資源站點就會跳出打卡任務，收集印章，陪伴夥伴也會一起長大。

## 🔗 立即使用

用手機瀏覽器開啟：**https://jiens77.github.io/pu-walk/**

建議使用 iPhone 的 Safari，或 Android 的 Chrome。

## 🚶 使用方式

1. 按「開始探索」
2. 選一位走讀夥伴
3. 勾選你感興趣的主題
4. 允許瀏覽器取得「位置」權限
5. 跟著地圖走，靠近站點時手機會震動提醒，按「打卡」完成任務

> 💡 不在校園、或沒開定位時，可以直接點地圖「模擬走路」先預覽。

| --- | --- |
| 0　剛報到的新生 | 開始探索 |

**小修女**會在特別的時刻出現：校門口迎接你、在主顧聖母堂歡迎你、在文興樓陪你聊聊心事，並在走讀結束時給你祝福。

## 📍 11 個資源站點

**學習資源區**
- 蓋夏圖書館：借書、自習空間（文興樓東側）
- 主顧樓：行政單位（校區北側）

**生活支持區**
- 文興樓：行政、學務、諮商輔導、醫療保健
- 宜園餐廳：離校門最近的餐廳（任垣樓西側）
- 靜園餐廳：校園中段的用餐地點
- 希嘉學苑：學生宿舍（主顧聖母堂南側）
- 綜合運動場：校區西南側
- 若望保祿二世體育館：校區西側

**發展探索區**
- ✝ **主顧聖母堂**：校園心靈地標（靜園餐廳南側）
- 至善樓（活動中心）：社團與學生活動
- 櫻花步道：任垣樓東南側

## ✅ 每站四個任務

1. **找到它**：走到站點附近，自動觸發
2. **破冰一下**：回答一個小問題或提示
3. **蓋章驗證**：收進你的走讀護照
4. **記下收穫**：寫下一件你學到的事

## ⚠️ 注意事項

- 需要使用 **https** 網址，GPS 才能運作（GitHub Pages 已支援）
- 若跳出「未授權定位」，請到手機的「設定 → 瀏覽器 → 位置」開啟權限
- 室內或高樓旁 GPS 可能有 10～30 公尺誤差，靠近一點再試試
- 走讀紀錄只存在這次瀏覽，重新整理或關閉分頁後會重新開始
